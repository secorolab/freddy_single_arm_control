## Motion Specification ActionServer

### Tested on
- OS: Ubuntu 24.04

### Dependencies
- motion_specificatoin_interfaces
- libyaml-cpp-dev (system package)
- nlohmann_json (system package)
- orocos_kdl
- kdl_parser
- kinova_mediator
- Eigen3

### Installation

- System packages

```
sudo apt install libyaml-cpp
sudo apt install nlohmann-json3-dev

```

- ROS packages

```
motion_specification_server
kinova_mediator

```
